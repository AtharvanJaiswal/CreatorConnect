# CreatorConnect — Architecture & Operational Risk Register

## 1. Risk Evaluation Framework

Risks are quantified based on **Probability** (1: Low to 5: High) and **Impact** (1: Low to 5: Critical). The **Risk Score** = Probability × Impact (1 to 25).

---

## 2. Comprehensive Risk Matrix

| ID | Risk Category | Risk Description | Prob (1-5) | Imp (1-5) | Score | Mitigation Strategy | Detection Mechanism | Contingency Plan |

| **RSK-01** | **Financial** | **Double Spend / Escrow Overpayment**: Duplicate webhook processing causes duplicate payouts to creators. | 2 | 5 | **10** | Strict idempotency keys on payment records; atomic database transactions; double-entry ledger verification. | Sentry alerts on duplicate webhook attempts; automated ledger balance check. | Immediate freeze on user payout account; manual reconciliation run by finance admin. |

| **RSK-03** | **Architecture** | **WebSocket Connection Storm / Thread Starvation**: Chat traffic spikes consume all Node.js event loop cycles, delaying checkout/REST responses. | 3 | 4 | **12** | Physically isolate Realtime Gateway into a dedicated container tier; use Redis pub/sub adapter; implement connection rate limiting. | Prometheus/Pino metric on active socket count, event loop lag > 50ms. | Fastify auto-shedding / graceful throttling of new incoming socket handshakes. |
| **RSK-04** | **Technical** | **Outbox Relay Event Loss / Duplicate Dispatch**: Event worker crashes during batch publication to BullMQ. | 2 | 4 | **8** | Polling worker uses `SKIP LOCKED` SQL transactions; updates outbox row to `PROCESSING` atomically; consumer queues enforce idempotency keys. | Outbox lag metric (events older than 60s in `PENDING` status). | Re-enqueue daemon automatically picks up stuck `PROCESSING` events after 5-min timeout. |
| **RSK-05** | **Security** | **Malicious File Upload (Shell / Malware in Video/Zip)**: Attackers upload disguised malware to compromise platform or clients. | 3 | 4 | **12** | Presigned URL upload enforces strict MIME validation via Content-Type header; background worker validates magic bytes and runs ClamAV scan. | ClamAV worker detection log; Sentry alert on malformed file headers. | Immediate deletion of object from Cloudflare R2; quarantine user profile and suspend account. |
| **RSK-06** | **Operational** | **Third-Party Service Outage (Supabase Auth / Razorpay)**: Core identity or payment processor encounters downtime. | 2 | 4 | **8** | Fast failure handling with user-friendly RFC 7807 error messages; circuit breaker to avoid cascading timeouts; cached public profile views. | Uptime monitoring pinging health check endpoints; Sentry 5xx surge alert. | Display platform banner indicating maintenance mode for payments/login; defer non-critical jobs. |
| **RSK-07** | **Performance** | **Search Latency Degradation as Profile Catalog Scales**: PostgreSQL FTS (`tsvector`) queries become slow with 100k+ profiles. | 3 | 3 | **9** | GIN indexing on `tsvector` columns; materialized view pre-aggregating creator ratings and skills; pg_trgm threshold tuning. | PostgreSQL slow query log (>200ms); Pino APM search duration metric. | Trigger Phase 15 extraction of dedicated search engine (OpenSearch/Typesense). |
| **RSK-08** | **Product** | **Retaliatory Review Extortion**: Clients or freelancers giving 1-star reviews maliciously during price/scope negotiations. | 4 | 3 | **12** | Double-blind review system: reviews remain completely hidden until both parties submit or 14 days lapse; dispute escalation mechanism. | Automated anomaly detection on review sentiment vs project milestone completion. | Platform dispute arbitrator reviews chat transcripts and contracts; has authority to suppress fraudulent reviews. |
| **RSK-09** | **Compliance** | **Data Leakage in Application Logs**: Sensitive credentials or PII accidentally emitted to log aggregation platform. | 2 | 4 | **8** | Native Pino redaction paths for passwords, tokens, bank accounts, and headers; automated pre-commit hook preventing log of raw payloads. | CI/CD Gitleaks scanner; log anomaly alerts in monitoring dashboard. | Immediate log retention purge; rotate compromised credentials; file incident report. |
| **RSK-10** | **Engineering** | **Contract Drift Across Frontend / Mobile / Backend**: API changes break mobile app or web microfrontends unexpectedly. | 3 | 4 | **12** | Strict API-First OpenAPI 3.1 workflow; all client types generated via Orval / `openapi-typescript`; CI runs contract validation on every PR. | CI build failure on schema mismatch; breaking change detector in GitHub Actions. | Block merge until client libraries and consumers are updated and tested. |
