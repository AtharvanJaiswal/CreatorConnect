Assignments & Projects UI

Full mobile UI specification for Module G: screens G01 through G20 and dialog overlays DLG-G01 through DLG-G08. Built on the approved design system (#FAF6EF cream background, #FFD64A pill buttons, Archivo bold typography, 375×812 phone frames). Covers the dual workflows of Assignment Posting (Brand/Poster cockpit, 5-step brief creation, applicant shortlisting, hiring) and Assignment Application (Creator discovery feed, pitch submission, proposal inspection, milestone tracking, and completion sign-off).

Data Mapping & SOW Schema Reconciliation

Screen ID SOW Clause Required Schema & Data Fields State / Trigger
G01 SOW §11 (Assignments Feed) assignment_id, poster_brand, title, budget_min, budget_max, deadline, skills_tags, location Creator taps Assignments navigation tab
G02 SOW §11 (Brief Detail) full_description, deliverables_list, brand_rating, verified_status, escrow_flag Creator taps an opportunity card
G03 SOW §12 (Submit Application) proposed_rate_inr, estimated_days, pitch_text, attached_portfolio_ids[] Creator taps 'Apply for Brief'
G04 SOW §12 (Application Tracker) application_status (applied, shortlisted, hired, rejected), quoted_rate, client_reviewed_at Creator views 'My Applications' list
G05 SOW §11 (Poster Cockpit) active_briefs_count, applicants_count, shortlisted_count, budget_allocated Brand views 'My Briefs' dashboard
G06–G10 SOW §11 (Post Brief Wizard) category_id, subcategory_id, skills[], title, description, location, budget_range, deadline Brand initiates 5-step posting flow
G11 SOW §11, §12 (Applicant Triage) applicant_profile, match_score, bid_inr, portfolio_links, shortlist_flag Brand reviews applicants for an assignment
G13 SOW §11, §18 (Milestone Tracker) milestone_title, due_date, status (pending, submitted, approved), escrow_amount Active contracted collaboration workspace
G16 SOW §11, §16 (Project Completion) final_signoff_at, invoice_pdf_url, rating_prompt_flag Brand approves final milestone deliverable
Backend Engineering Architecture Note (Fastify + Prisma):
1. Escrow State Machine: Assignment status transitions follow strict validation: Draft → Published → Applications_Open → In_Progress → Completed.
2. Rate Quoting: Proposed rates are validated to ensure they fall within or close to reasonable client budget boundaries.
3. Direct Chat Handoff: When a candidate is selected, an automated trigger initiates an assignment-linked chat room in Module G (Real-Time Chat) with the brief header pinned.
