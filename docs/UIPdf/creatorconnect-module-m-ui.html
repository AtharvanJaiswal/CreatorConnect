Scope & Architecture

Technical Implementation Notes for Engineering & Fastify Microservices:

1. Database Schema (PostgreSQL): Relational tables for referral_codes, referrals (linking referrer and referee with status enum: pending, qualified, rewarded, flagged), affiliate_ledger, and payout_requests.

2. Escrow Milestone Trigger: When a referee completes their first escrow milestone sign-off (SOW §8), a webhook triggers ReferralService.rewardReferrer(refereeId) to credit £25 to the referrer's affiliate ledger.

3. Anti-Fraud Rules (R18): Automatic checks verify that referrer_id != referee_id, referrer_ip != referee_ip, and both accounts maintain verified status. Flagged referrals route to admin queue R18 for manual review.
