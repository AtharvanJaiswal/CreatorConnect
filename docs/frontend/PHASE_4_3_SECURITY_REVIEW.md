## 2. Residual Attack Surface & Fail-Closed Guarantees

1. **Inline Styles (`style-src 'self' 'unsafe-inline'`):** Retained deliberately in CSP to support Next.js style injection and 2 runtime-dynamic React style attributes (`attachment-viewer.tsx:273` zoom transform, `verification-centre-panel.tsx:711` progress width). All script execution paths remain blocked by strict per-request nonces and `'strict-dynamic'`.
2. **Legacy Consumer Routes Checking `roles.includes('ADMIN')`:** Existing creator/brand-facing endpoints (`payments.routes.ts`, `cancellations.routes.ts`, `projects.routes.ts`, `reviews.routes.ts`, `messaging.routes.ts`, `profiles.routes.ts`, `account-lifecycle.service.ts`) still use role-level `'ADMIN'` flags for moderation/admin overrides and were intentionally left compatible with existing Phase 6 tests. Full inventory is in [`PHASE_4_3_AUTHORIZATION_MATRIX.md`](./PHASE_4_3_AUTHORIZATION_MATRIX.md).
3. **E2E Test-Only Auth Helpers (`createTestJwt`):** `window.__TEST_ACCESS_TOKEN__` / `creatorconnect_test_access_token` in `api-client.ts` and `auth-provider.tsx` are harmless unless the API backend runs against a test JWKS key (`SUPABASE_JWKS_URL`); production boot guard rejects HTTP JWKS and localhost issuers (`jwt-verifier.ts`).
